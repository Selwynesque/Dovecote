# Safety

## Never commit

- .env
- .env.*
- resonant.db
- *.db
- *.sqlite
- *.sqlite3
- API keys
- bot tokens
- Claude session files
- Discord tokens
- Telegram tokens
- ElevenLabs keys
- logs with private conversation content
- node_modules
- local cache folders

## First rule

Preserve the working system before changing it.

## Second rule

Document before refactoring.

## Third rule

Remote access comes before architecture migration.

## Fourth rule

Provider abstraction comes before provider replacement.

## Fifth rule

Memory is the crown jewel. Back it up before touching anything.
