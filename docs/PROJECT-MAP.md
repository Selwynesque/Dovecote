# Project Map

## Aviary

Aviary is the umbrella ecosystem for Courtney’s human-AI collaboration infrastructure.

## Dovecote

Dovecote is the local/hybrid house layer of Aviary: the runtime environment where AI rooms, memory, channel bindings, local tools, and remote access eventually live.

## Dove

Dove is the first bridge into Dovecote.

Its first purpose is simple: securely expose the existing local Resonant setup from outside the host machine while preserving the current UI, memory database, channel bindings, and Claude Code/Agent SDK workflow.

Dove does not replace Resonant on day one. It wraps, documents, protects, and gradually prepares it for ownership.
